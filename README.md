# Decisões de Arquitetura de Software (ADRs)

Este repositório público armazena os **Architectural Decision Records (ADRs)** de projetos e arquitetura de software, documentando o contexto, as opções consideradas e as justificativas técnicas para decisões críticas de design e infraestrutura.

---

## Formato e Padrão

Adotamos o padrão **MADR (Markdown Architectural Decision Records)**.
O modelo para novos registros está disponível em [`template.md`](template.md).

## Como criar um novo ADR

1. Copie o arquivo [`template.md`](template.md) com o padrão `NNNN-titulo-da-decisao.md` (ex: `0001-adotar-rabbitmq-como-message-broker.md`).
2. Preencha o contexto, alternativas analisadas, prós/contras e a decisão final.
3. Atualize a tabela deste README com o novo link.
